# Solton Technical Services Ltd website\n\nResponsive Next.js App Router website built from the company profile and design reference.\n\nRun npm install, then npm run dev. Open http://localhost:3000. Production checks: npm run lint, npm run typecheck, npm run build.\n\nTo enable form email delivery, configure RESEND_API_KEY, CONTACT_TO_EMAIL, and CONTACT_FROM_EMAIL. Otherwise the endpoint reports that delivery is not configured and does not claim a message was sent.\n\nNo official logo was included, so SiteLogo.tsx contains a temporary text wordmark. Team portraits are stock placeholders; project photos are illustrative. See PHOTOGRAPHY.md.\n
